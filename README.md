## About

This repo documents my journey in **Cloud Penetration Testing**. It includes:

- **Writeups** for AWS-related vulnerabilities and labs/CTFs.
- **Tools** I build to speed up scanning and exploitation in cloud environments.
- **Exploits** for vulnerabilities discovered or researched along the way.

The content is organized by topic and will keep growing as I progress.
